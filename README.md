# Eilik Robots — پکیج آماده‌ی ساخت APK

## توی این زیپ چی هست؟

```
eilik-robots-project/
├── www/
│   ├── index.html          ← فایل بازی (نسخه‌ی راند ۳۲)
│   └── fonts/
│       └── vazirmatn.css   ← فایل موقت؛ موقع build خودکار با فونت واقعی (آفلاین) جایگزین میشه
├── config.xml               ← تنظیمات اپ: فول‌اسکرین + دسترسی‌های میکروفون/لرزش
├── icon.png                 ← آیکون پیش‌فرض (می‌تونی با آیکون خودت از ChatGPT جایگزینش کنی)
├── .gitignore
└── .github/
    └── workflows/
        └── build-apk.yml    ← اسکریپت GitHub Actions که خودش APK می‌سازه
```

## قدم‌به‌قدم

### ۱. آپلود توی گیت‌هاب
یه ریپازیتوری جدید (public یا private) بساز، همه‌ی فایل‌های این زیپ رو (با همین ساختار پوشه‌ها) توش آپلود کن.

### ۲. (اختیاری ولی پیشنهادی) جایگزینی آیکون
آیکونی که با پرامت ChatGPT ساختی رو دانلود کن، بهش اسم `icon.png` بده و فایل موجود توی روت ریپو رو باهاش عوض کن (باید مربعی و ترجیحاً ۱۰۲۴×۱۰۲۴ باشه).

### ۳. اجرای build
برو به تب **Actions** بالای صفحه‌ی ریپو → روی workflow به اسم **Build APK** کلیک کن → دکمه‌ی **Run workflow** رو بزن.
(با هر push به شاخه‌ی main هم خودش اجرا میشه.)

### ۴. دانلود APK
چند دقیقه صبر کن تا build تموم بشه (نشان سبز ✅). بعد وارد همون run بشو، پایین صفحه بخش **Artifacts** رو باز کن و فایل `eilik-robots-apk` رو دانلود کن — یه زیپ کوچیکه که خود APK توشه.

## توضیح چیزایی که تنظیم شده

- **فول‌اسکرین:** با `Fullscreen=true` و تنظیمات StatusBar توی `config.xml`.
- **آفلاین بودن کامل:** یه مرحله‌ی مخصوص توی workflow («Fetch offline fonts») هست که همون لحظه‌ی build، فونت‌های Vazirmatn و Press Start 2P رو واقعاً دانلود می‌کنه و به‌صورت فایل محلی داخل `www/fonts` می‌ذاره. این یعنی خود فایل‌های فونت داخل APK نهایی قرار می‌گیرن و روی گوشی کاربر هیچ اینترنتی لازم نیست — چون این پروژه از localStorage هم استفاده می‌کنه (برای حافظه/باتری/اسم ربات‌ها) که اونم توی WebView به‌صورت لوکال کار می‌کنه.
- **دسترسی‌ها:** توی `config.xml`، `RECORD_AUDIO` (میکروفون، برای واکنش به صدا)، `VIBRATE` (لرزش) و `MODIFY_AUDIO_SETTINGS` به مانیفست اضافه شدن.

## ⚠️ نکته‌ی مهم درباره‌ی میکروفون

اندروید ۶ به بعد (اکثر گوشی‌ها) علاوه بر مجوز توی مانیفست، یه بار هم باید موقع اجرای برنامه از کاربر runtime permission بگیره. توی وب‌ویوی ساده‌ی کوردوا، این درخواست معمولاً خودش هنگام اولین استفاده از میکروفون (`getUserMedia`) توسط کروم داخلی گوشی نمایش داده میشه — یعنی احتمالاً همین الان هم کار می‌کنه. اگه بعد از تست دیدی مجوز میکروفون درخواست نمیشه یا رد میشه، بگو تا پلاگین اختصاصی `cordova-plugin-android-permissions` رو هم اضافه کنم و کد لازم برای درخواست دستی مجوز رو توی `index.html` بذارم.

## ⚠️ نکته درباره‌ی انتشار در بازارها

APK ای که این workflow می‌سازه **امضا‌نشده (unsigned)** است:
- برای نصب مستقیم روی گوشی یا آپلود توی خیلی از بازارهای داخلی (مثل کافه‌بازار)، معمولاً مشکلی نیست — یا خودت امضا می‌کنی یا بازار خودش امضا می‌کنه.
- برای Google Play حتماً باید امضا (sign) و zipalign بشه. اگه به اون مرحله رسیدی بگو، قدم‌به‌قدم روش امضا کردن APK رو هم برات می‌نویسم.

## تغییر اسم پکیج (اختیاری)
اگه می‌خوای بازار یا گوگل پلی رو با یه شناسه‌ی اختصاصی خودت ثبت کنی، توی `config.xml` مقدار `id="com.eilik.robots"` رو با چیزی مثل `com.yourname.eilikrobots` عوض کن (قبل از build).

## 💰 تبلیغات و کسب درآمد (تپسل)

این پروژه از حالا پلاگین تبلیغات **تپسل** (`tapsell-v3-cordova-plugin`) رو داره — هم توی `config.xml` و هم توی workflow اضافه شده، و کدش هم ته فایل `www/index.html` نوشته شده (یه بنر پایین صفحه + یه تبلیغ تمام‌صفحه هر چند دقیقه یک‌بار).

**قبل از build باید این کارها رو انجام بدی:**

1. توی [پنل تپسل](https://tapsell.ir) ثبت‌نام کن و اپلیکیشنت رو با همون Package Name که توی `config.xml` گذاشتی (`com.eilik.robots` یا هرچی خودت گذاشتی) ثبت کن.
2. یه **App Key** برای اپلیکیشن می‌گیری.
3. برای بنر و برای تبلیغ تمام‌صفحه، جدا جدا **Zone** تعریف می‌کنی (توی پنل تپسل، بخش Zones) و **Zone ID** هر کدوم رو کپی می‌کنی.
4. توی `www/index.html`، پایین فایل، دنبال این سه خط بگرد و مقدارهاشون رو با چیزی که از پنل گرفتی عوض کن:
   ```js
   var TAPSELL_APP_KEY        = "APP_KEY_خودت_رو_اینجا_بذار";
   var TAPSELL_BANNER_ZONE    = "ZONE_ID_بنر_رو_اینجا_بذار";
   var TAPSELL_INTERSTITIAL_ZONE = "ZONE_ID_تمام‌صفحه_رو_اینجا_بذار";
   ```
5. push کن و دوباره workflow رو اجرا کن.

نکته‌ها:
- تا وقتی این سه مقدار رو عوض نکنی، تبلیغی نمایش داده نمیشه (کد خودش چک می‌کنه و کاری نمی‌کنه، خطا هم نمیده).
- تبلیغ تمام‌صفحه از این حالا **خودکار** نمایش داده میشه، بدون اینکه لازم باشه دستی جایی صداش کنی:
  - یه بار حدود ۲۰ ثانیه بعد از باز شدن اپ (بعد از انیمیشن بوت)
  - و بعدش هر ۶ بار که کاربر یه پیام/دستور به ربات‌ها میده (توی تابع `runCommand`)
  - در هر دو حالت، حداقل ۳ دقیقه فاصله بین دو تبلیغ رعایت میشه (با `INTERSTITIAL_MIN_GAP_MS`) تا کاربر رو فراری نده
- اگه دیدی خیلی زیاده یا خیلی کمه، همون عدد ۶ رو توی `index.html` (`adCommandCounter % 6`) کم‌وزیاد کن.
- تپسل برای اپ‌های داخل ایران مناسبه چون از سرورهای داخلی کار می‌کنه و نیازی به VPN یا حساب گوگل نداره؛ در ازاش هزینه‌ی نمایش تبلیغ (eCPM) معمولاً از AdMob کمتره.
